## ✨ Fonctionnalités

| | |
|---|---|
| 🎬 **Tous les formats** | Vidéos, Shorts, lives, playlists et chaînes |
| ✂️ **Liens courts** | Format `/v/ID` plus lisible, avec libellé personnalisé |
| ⏱️ **Moment de départ** | La vidéo démarre pile au bon moment |
| 📦 **Conversion en masse** | Colle 10, 50, 100 liens d'un coup |
| 📱 **QR code** | À enregistrer et partager en un tap |
| 🕘 **Historique** | Tes derniers liens, gardés sur ton appareil |
| 🎨 **Personnalisation** | 7 couleurs pour la page d'ouverture |
| 🔒 **Zéro donnée** | Aucun compte, aucun suivi, rien n'est envoyé |

## 🚀 Comment ça marche

1. 📋 **Colle** un lien YouTube
2. ⚡ **Clique** sur *Créer le deep link*
3. 💬 **Partage-le** dans ta bio, tes stories ou tes messages

## 🌍 Où ça marche ?

| Plateforme | Résultat |
|---|---|
| 📸 Instagram · Facebook · Threads | ✅ Ouvre l'app YouTube |
| 🎵 TikTok · Snapchat · X · LinkedIn | ✅ Ouvre l'app YouTube |
| 🤖 Android | ✅ Ouverture directe |
| 🍎 iPhone | ✅ Ouverture auto, ou bouton de secours |
